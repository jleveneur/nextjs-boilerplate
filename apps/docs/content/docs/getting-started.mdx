---
title: Getting started
description: Install the monorepo, start local dependencies, and run the apps.
---

Requires [Node.js](https://nodejs.org) 24+, [pnpm](https://pnpm.io) 12+, and
[Docker](https://docs.docker.com/get-docker/). `make help` lists every target.

## Install

```bash
make setup       # install, root `.env`, `apps/docs/.env`, deps, migrate, seed
make check       # format, lint, typecheck, layers, tests — same gates as CI
```

Or step by step:

```bash
pnpm install
cp .env.example .env
cp apps/docs/.env.example apps/docs/.env   # docs site (port 3003)
make deps-up     # Postgres, Redis, MinIO, Mailpit, OTel/Jaeger, …
make db-migrate
make db-seed     # optional demo data
```

Configuration is validated by `@repo/env`. App env modules select the
`process.env` values they accept and pass them to `createEnv`; reusable libraries
consume typed configuration rather than ambient state. The docs app only needs
the public preset in `apps/docs/.env`.

## Run the apps

```bash
make dev         # deps + all apps → https://web.localhost
```

Portless serves HTTPS `*.localhost` URLs (proxy on 443). First start may prompt
to trust the local CA (`portless trust`). `PORTLESS=0` uses localhost ports
instead: web `3000`, api `3001`, worker `3002`, docs `3003`.

Individual apps:

```bash
pnpm --filter @repo/web dev
pnpm --filter @repo/api dev
pnpm --filter @repo/worker dev
pnpm --filter @repo/docs dev
```

Or build images and run the prod-like stack:

```bash
make images
make prod-up     # Traefik on :8080 — web at localhost, docs at docs.localhost
```
